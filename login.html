Locally hosting the backend?


If you are editing the backend or wanting to locally host it on your device in order for this website to use your backend instead of the one we host for you simply click the button below to enable local host mode which will set the URI from our self-hosted api to the api at, "http://127.0.0.1:5500/"

If you are not happy with the API endpoint URI chosen for local host mode go into "JS/FrontJS/button.js" and change the "localURI" variable to your endpoint

A quick tip: When putting in your URI it NEEDS to end with a forward slash -> /

If you dont know what your local URI is when running a express script via node.js it will almost always be your private ip + port so like this: http://IP:PORT/
